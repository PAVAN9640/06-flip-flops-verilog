# Flip-Flops using Verilog

Digital Design Project #6: Implementation and simulation of SR, D, JK, and T Flip-Flops using Verilog HDL in Xilinx Vivado.

## Overview

This project demonstrates the design and simulation of fundamental sequential circuits known as flip-flops. Flip-flops are basic memory elements used in digital systems to store one bit of information.

## Modules Implemented

* SR Flip-Flop
* D Flip-Flop
* JK Flip-Flop
* T Flip-Flop

## Tools Used

* Verilog HDL
* Xilinx Vivado

## Files

### SR Flip-Flop

* sr_flipflop.v
* sr_flipflop_tb.v

### D Flip-Flop

* d_flipflop.v
* d_flipflop_tb.v

### JK Flip-Flop

* jk_flipflop.v
* jk_flipflop_tb.v

### T Flip-Flop

* t_flipflop.v
* t_flipflop_tb.v

## Simulation Results

Each flip-flop was verified using a dedicated testbench and simulated in Vivado. The waveforms confirm the expected behavior of each sequential circuit.
